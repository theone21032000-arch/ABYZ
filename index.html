# StudentFlow — Product implementation

Build a responsive web application that helps students understand their academic progress and know what to do next.

## Core experience
- A personal dashboard for courses, grades, attendance and deadlines.
- Clear, actionable progress signals; never use status color alone.
- A calm, accessible interface that avoids overwhelming students.

## Actors
- Student: can view their own academic information.
- Academic advisor: can identify and contact students needing support.

## Open decision
The criteria that trigger an advisor alert is not defined. Do not infer it: add an explicit configuration point.
